## 1. 背景与目标

团队 AI 网关（LiteLLM Proxy + Next.js 控制台）核心链路已打通，适合小范围内测。  
本工单目标：补齐**上线前安全与运维门槛**、**管理端真数据**、**预算防绕过与多副本能力**，并规划增强项。

### 1.1 已就绪（无需再开需求）

| 能力 | 说明 |
|------|------|
| 网关 | DeepSeek / MiMo 别名、CNY 价目、峰谷、Postgres Spend、Compose |
| 账号 | 手机号登录、首登改密、`passwordVersion`、禁用用户 |
| Key | Virtual Key 签发 / 轮换；Playground 服务端代理 |
| 对话 | `/api/chat` 流式、思考深度、写 `SpendEvent` |
| 个人看板 | `/api/me/analytics` + `/dashboard` |
| 模型页 | 目录 + 文档弹层（调用示例 / 官方说明） |
| 皮肤 | 8 套深定制；进入页品牌钉死 |
| 部署脚本 | `scripts/env-init.sh` · `deploy.sh` · `test.sh` |

### 1.2 明确不做（沿用交接边界）

- 短信验证码、开放自助注册、SSO  
- 充值 / 发票、多 Key 管理 UI  
- 用 LiteLLM 官方 Admin UI 当产品登录页
