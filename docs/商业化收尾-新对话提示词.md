## 踩坑备忘（省你几小时）

- Git Bash 里 curl 内联中文会变 GBK，上游 UTF-8 解析失败 → 请求体写 UTF-8 文件用 `--data-binary @file`；node 脚本里别用 `/c/...` 路径（会解析成 `C:\c\...`）
- 停服务时 TaskStop/kill 可能留残余 node/python 进程占端口 → `netstat -ano | grep ":3000 "` 找 PID 再 `taskkill //PID x //F`
- 长跑网关进程内存缓存陈旧会让预算闸失效（user_object.max_budget 不刷新）→ 重启即愈；排查预算问题先重启再测
- LiteLLM 密钥 API：`/key/list` 要 `return_full_object=true`；操作用 sha256 哈希 token（不是 key_name）；有效期用 `duration` 参数（"7d"，null=永久）；**IP 白名单是企业版功能，免费版做不了，别承诺**
- Python litellm 1.91.1 在 `D:\PythonUser\Python310\site-packages`；DB 模式依赖 `pip install prisma` 且要对 `litellm/proxy/schema.prisma` 跑过 `python -m prisma generate`；首次启动慢（Defender 扫描 query-engine），失败可重试
- 仓库可能有多个会话并行改过代码（余额系统、SSE 解析、能力表第三列等是另一会话加的）——**改文件前先读当前内容**，别覆盖他人改动
